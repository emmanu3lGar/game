The program helps you make better decision by having you choose what 
words help your brain grow. And then you can use them to say them to 
yourself and have more confidence in yourself. The program is useful 
for learning which things make your brain develop, and not have a 
fixed brain. Which wont help you grow as a person.

How can you start this project?

First to be able to run this program correctly you need to have
python 3, and also download pygame. The program 
was build with python's pygame module. To be able to run the program 
you need to run the main.py file.
